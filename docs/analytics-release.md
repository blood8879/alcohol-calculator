## Verified Firebase linkage

- Android and iOS service config files both identify Firebase project `alcohoal-calculator` (project number `326931345291`) and package/bundle `com.jiamyun.alcoholcalculator`.
- A read-only Firebase Management API call to `GET /v1beta1/projects/alcohoal-calculator/analyticsDetails` returned GA4 property `493637962` and two app stream mappings. This proves the Firebase-to-GA4 link, not that events reached GA4.
- The authenticated `gcloud` user can read the Firebase project, but its cached token lacks the `analytics.readonly` scope and the GA4 Data API returned HTTP 403. The existing signed-in Aside browser can read the property. For August 26–September 22, 2026 (28 days), the Events report showed **168 events, 23 total users, and $0.00 total revenue**: `user_engagement` 54 (9 users), `calculator_used` 41 (7 users), `session_start` 25 (13 users), `screen_view` 24, `first_open` 22, `app_remove` 1, and `encyclopedia_viewed` 1. These are observed event totals, not a conversion or retention estimate. The new release events still require post-release verification.

Using the existing GA4 console, 27 event-scoped custom dimensions were created for the reviewed event parameters: `analytics_version`, `calculator_type`, `entry_source`, `close_reason`, `had_result`, `field_index`, `preset_id`, `section`, `source`, `target`, `content_kind`, `item_id`, `filter`, `query_length`, `result_count`, `mode`, `category`, `correct`, `progress_bucket`, `ad_format`, `placement`, `failure_reason`, `reason`, `outcome`, `preference`, `type`, and `duration_bucket`. The console now reports 27 definitions. No health inputs or raw query contents were registered.
- The property initially had zero Google AdMob links. An existing AdMob app for `com.jiamyun.alcoholcalculator` (`ca-app-pub-7612314432840835~3082062514`) was linked to the existing Android stream `11365391285` in GA4 property `493637962`. The console confirms one link. The wizard showed no ad-personalization option, and no such setting was changed. Google says linked data usually appears within one hour but can take up to 48 hours; the pre-link $0.00 GA4 revenue report should not be treated as current AdMob revenue. The AdMob app overview showed US$0.03 estimated revenue and 33 impressions for its last seven days at audit time.
- AdMob console confirmed that the formerly configured `~5764066171` value was the suffix of the existing banner **ad unit** `/5764066171`, not this app's ID. It also confirmed the existing quiz interstitial unit `/7447353245`; the repo previously used the app-ID suffix as that unit ID. The Android app ID in `app.json` and `AndroidManifest.xml`, and the quiz interstitial ID in `utils/adUnits.ts`, were corrected to the console values. The other existing ad unit IDs were preserved.
