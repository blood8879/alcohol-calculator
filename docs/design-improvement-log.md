# 디자인 개선 루프 기록

refero.design 레퍼런스 기반 리디자인(트래커·홈, `design-references-refero.md`) 이후의 반복 개선 기록.
매 회차: **점검(실제 렌더 + 명세서 대조) → 우선순위 → 구현 → 검증(tsc·jest·웹 렌더)**.

## 0회차 — 기반 리디자인 (2026-10-03)
- 트래커: 상태 타일, 빠른 기록 + 되돌리기, 일 요약 칩, 통합 통계 카드
- 홈: 세션 상태 카드(펄스·경과 시간), 오늘 카드 통합, 이번 주 타일, 퀴즈 행 카드, 이어 보기 레일
- 검증 중 수정: 홈 추천 행에서 팁 라벨과 같은 뱃지가 중복되어 제목이 잘리던 문제 → 같은 라벨이면 뱃지 생략, 제목 2줄

## 1회차 — 트래커 다듬기 + 공통 상태 컴포넌트 (명세서 §2.5)
점검에서 발견한 문제:
1. 주간 통계 차트 y축이 잔 수인데 `0.5, 1.5` 같은 소수 눈금이 나옴.
2. 지출이 없을 때 스탯 타일이 2×2 중 한 칸이 비어 어색함.
3. 섹션 헤더 스타일이 섞여 있음(`빠른 기록` 작은 회색, `오늘의 기록` 흰색 큰 글씨, 홈은 `SectionHeader`).
4. 기록 삭제가 확인 없이 즉시 실행 → 실수로 지워도 되돌릴 수 없음(명세서 "undo 토스트 제안 환영").
5. 빈 상태가 화면마다 제각각(명세서 §2.5 "빈 상태 템플릿 1종으로 통일").

**결과(검증 완료)**: 정수 y축 스케일 헬퍼(`utils/chartScale.ts`), 지출 없을 때 3열 타일, `SectionHeader` 통일(accessory 슬롯 추가), 삭제 → 되돌리기 토스트(`restoreDrinkLog`로 id·시각 그대로 복원), 공통 `EmptyState`(트래커·세션 히스토리·계산 기록). 웹 렌더로 삭제→빈 상태→복원 확인. jest 29 suites / 146 tests 통과.

## 2회차 — 계산기 바텀시트 다크 통일 (명세서 §3.2 "최우선", "다크 통일 필수")
점검: 앱 전체는 다크인데 계산기 시트만 흰 배경. 9종이 `CalculationCard` 템플릿 1개를 공유한다.

| Napper | 다크 시트 안 **값 + 인라인 단위 세그먼트**, 큰 알약형 주 버튼 | `239/mobile/9ef6983a-0c09-47cf-b28b-b865ad154337` |
| PayPal Amount | 입력(작은 라벨) → **결과 초대형 숫자** + 보조 환산 줄 | `213/mobile/68209316-578c-4596-8f2f-cbdc0423ed12` |

적용:
1. 시트 배경 `background` 토큰 + 상단 그랩 핸들, 제목·설명 흰/회색.
2. "이 계산기는 무엇인가요?" 접이식 안내 → `surface` 카드.
3. 프리셋 칩 다크(선택 시 accent).
4. 숫자 입력 → **Revolut식 그룹 카드 행**: 라벨 좌, 값 우측 정렬 + 단위, 행 구분선, 포커스 시 accent 테두리.
5. 결과 블록 → **PayPal식 위계**: 첫 결과 = 주인공 숫자(초대형, accent), 나머지는 보조 행. 오류는 같은 블록에 빨강 + 아이콘.
6. 공유·추천·닫기 버튼 다크 스타일, 키보드가 [계산하기]를 가리지 않게.

**결과(검증 완료)**: 칼로리 계산기에서 소주 프리셋 → 계산 시 다크 시트, 우측 정렬 입력(360 / 16.5), 주인공 결과 `332.6 kcal` + 보조 행, 공유·추천·닫기 정상. 오류는 danger 테두리 + 아이콘 + `role=alert`.

**다음 회차 후보(기각)**: 칼로리 계산기 `332.6 kcal`이 §2.1 정수 규칙과 다르다고 봤으나, 별첨 B-1이 계산기 결과를 `332.6 kcal`로 명시 → 계산기는 소수 1자리, 트래커는 정수가 의도된 설계. 변경 없음.

## 3회차 — 라이브 세션 한 손·저조도 최적화 (명세서 §3.3 "최우선")
점검(웹 렌더, 3잔 진행 중): 히어로·칩 구성은 양호. 그러나
1. [세션 종료 & 저장]이 스크롤 아래 → 명세서 "종료 버튼 엄지 도달 범위" 미충족.
2. BAC 진행바에 임계(0.02/0.05/0.08) 표시가 없어 "바 위치"로 상태를 읽기 어려움(§4.7 색만으로 구분 금지).
3. 진행 중 뱃지에 경과 시간이 없음.
4. 레벨 전환 모션 없음(명세서 "전환 모션 제안 환영").

레퍼런스(refero.design):
| 앱 | 패턴 | 원본 |
|---|---|---|
| komoot 내비 | 상단 핵심 수치 바 + **하단 고정 컨트롤** | `234/mobile/3d2306c8-0cbd-433b-8127-b38ea90be7a1` |
| FocusPomo | **눈금 자 + 현재값 포인터** | `181/mobile/ae6fc60d-ba95-418f-933d-6c80e2872278` |
| RAD Weather 꽃가루 | 단계 막대 + 단계 라벨(LOW/VERY LOW) 병기 | `306/mobile/496fa9a2-bd1b-485e-8d55-6ffdb5b0dc17` |

적용:
1. 하단 고정 액션 바: 주 버튼 [세션 종료 & 트래커에 저장](safe-area 포함). [기록 없이 종료]는 스크롤 끝 텍스트 버튼으로 시각 차이 확대.
2. BAC 스케일: 4구간 색 띠 + 임계 눈금 라벨(0.02·0.05·0.08) + 현재값 ▲ 포인터.
3. 헤더 뱃지 `진행 중 · 1시간 12분`(홈과 같은 경과 시간 헬퍼).
4. 레벨이 바뀌면 히어로 숫자 색 전환 + 짧은 강조(감소 모션 설정 시 생략).
5. 빠른 잔 칩 2열 균등 폭(엄지 타깃 일정).
수식·고정 문구(§2.3)는 변경하지 않는다.

**3회차 결과(검증 완료)**: 웹 렌더에서 `진행 중 · 8분` 뱃지, 4구간 BAC 스케일 + 임계 라벨 + 포인터(0.039%가 0.02–0.05 구간에 위치), 2열 균등 잔 칩, 하단 고정 [세션 종료 & 트래커에 저장] 확인. 레벨 변화 시 색 전환 + 1.12× 펄스(감소 모션 시 생략). BAC 수식·임계·법정 문구 불변(임계 라벨이 `bacLevelOf` 경계와 일치하는지 테스트로 고정). 전체 jest 30 suites / 157 tests, tsc·eslint 통과.

**4회차 결과(검증 완료)**: 퀴즈 날짜 키를 로컬 날짜로 수정(`toLocalDateKey`), 같은 UTC 문제가 있던 `todayHub.dayIndex`도 수정 — 옛 코드로 되돌리면 7개 테스트가 실패하도록 고정. 대기 화면: 연속 카드(큰 숫자 + ⚡ + 요일 도트, 0일이면 "오늘 첫 퀴즈를 풀어보세요"), 주제 행 `최고 n/m` 뱃지, 선택 = 외곽선 + 체크, 하단 고정 [시작하기]. 결과: 주 버튼 1(광고 재도전) · 보조 1(점수 공유) · 텍스트 링크 행 + **문제 복기 목록**(✓/✗ + 내 답 + 정답). 웹 렌더로 5문제 풀이 → 복기 확인.

## 6회차 — 칼로리 계수 불일치 (데이터 정합성)
점검 중 발견: 소맥 레시피가 `140 kcal`로 표시되나 명세서 B-5는 `142 kcal`. 원인 — 레시피만 `×0.789×7`(≈5.52)을 쓰고 계산기·트래커·세션은 `×5.6`(명세서 B-2 계수). 같은 소맥을 트래커에 기록하면 142 kcal → 앱 안에서 숫자가 다름.
조치: 계수를 공용 상수 하나로 모으고 레시피도 5.6 사용.

## 8회차 — 레시피 id 중복
6회차 중 발견: `green-grape-soju`가 `cocktailRecipes.ts`(청포도 소주, 사이다)와 `extendedContent.ts`(청포도 소주 에이드, 주스+탄산수) 두 곳에 서로 다른 레시피로 존재 → 목록 key 충돌, 즐겨찾기 하나 누르면 둘 다 표시, 최근 본 콘텐츠가 엉뚱한 레시피로 열릴 수 있음.

## 17회차 — 시스템 글자 크기 200% (명세서 §4.7 "최대 200%에서 초대형 수치 카드가 파손되지 않도록")
개인 폰은 사용 중이라 설정 변경을 즉시 원복(font_scale 1.0)하고, 이 앱 전용 에뮬레이터(Alcohol_QA_API_34, 영어)에서 font_scale 2.0으로 점검:
1. 홈 계산기 그리드 라벨이 거의 전부 잘림(`ABV Adju…`, `Calorie C…`) — 1줄 말줄임 고정.
2. 탭바 라벨이 아래로 잘림(`Home`, `Explore` 하단이 광고에 가려짐) — 탭바 높이는 고정인데 라벨이 무제한 확대.

**17회차 결과(에뮬레이터 200% 재검증 완료)**: 글자 확대 상한을 `utils/fontScale.ts` 한 곳에 정의(탭 라벨 1.3 · 작은 셀 라벨 1.5 · 큰 숫자 1.3, 본문은 제한 없음). 계산기 그리드 라벨 2줄 + 최소 높이 → `ABV Adjustment`, `Calorie Calculator` 전부 표시. 탭 라벨 잘림 해소. 큰 숫자(BAC·D+n·n/한도·퀴즈 점수·최고 BAC·통계)는 한 줄 + 자동 축소. 날짜 셀·퀴즈 뱃지·BAC 눈금 행 고정 높이 → 최소 높이.

## 17b — 200%에서 트래커 헤더·카드 머리줄
- 헤더 제목이 `Drink T…`로 잘림 → 글자 배율 1.3 초과 시 제목 전폭 + 버튼 두 번째 줄.
- 인사이트 카드 비교 문구가 **카드 밖으로 넘침**(말줄임도 없이 잘림) → 머리줄 줄바꿈 허용.
- 같은 유형(제목 + 우측 값) 행 일괄 점검: SectionHeader, 주간 목표·챌린지 카드, 세션 기록 머리줄, 설정 스위치 행, 퀴즈 진행 행, 레시피 요약 행.
- 에뮬레이터 200% 재검증: `Drink Tracker / Today · Oct 4` 전부 표시, 비교 문구 카드 안 별도 줄 ✅. jest 40 / 294.
