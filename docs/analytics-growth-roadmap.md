# 1.2.5 출시 후 성장 분석 로드맵

## 확인된 기준선

GA4 브라우저 보고서의 2026년 8월 26일~9월 22일 집계는 사용자 23명, 이벤트 168건이다. 이벤트별로 `calculator_used` 41건, `first_open` 22건, `session_start` 25건, `encyclopedia_viewed` 1건을 확인했다. 이벤트 건수는 고유 사용자 수나 기능 완료율이 아니다. 이 기준선 당시 분석용 맞춤 측정기준이 없었지만 현재는 27개가 등록됐고 AdMob 연결도 확인됐다. GA4 보고서의 수익 $0는 광고 수익이 없었다는 뜻이 아니다. AdMob 자체 보고서는 최근 7일간 노출 33건과 수익 $0.03을 보여준다. 사용자 23명으로 기능의 우열이나 통계적 유의성을 주장하지 않는다.

## 단계별 결정

1. **1.2.5 측정 출시:** 2026년 9월 23일 최종 서명 Android AAB(버전 코드 25)의 검증과 Play 제출이 끝났으며 현재 심사 중이다. 같은 AAB에서 추출한 앱으로 홈과 맥주 500 ml·5% 계산 결과 140 kcal를 확인했고, 네이티브 스키마 2 이벤트는 서버 HTTP 204 응답을 받았다. 최종 콘솔 조회에서 이 이벤트의 수신은 아직 확인하지 못했다. 전체 26개 테스트 묶음·115개 테스트와 타입·린트 검사도 통과했다. 별도 EEA QA 전용 APK에서는 UMP 양식의 거부 선택 후 수집이 꺼진 상태를 확인했다. 동의 선택과 개인정보 선택 재열기 검증은 남아 있다. QA 전용 APK는 출시물이 아니다. 출시 후 `analytics_version=2`와 앱 버전 1.2.5만 별도 분석한다.
2. **2~4주 관찰:** 아래 주간 지표를 같은 정의로 기록한다. 유입 경로와 첫 유용한 계산 결과까지의 이탈을 먼저 본다. 표본이 적으면 추세와 개별 흐름의 관찰로만 남기고, 출시 전 데이터와 섞어 전후 효과를 단정하지 않는다.
3. **근거가 생긴 곳부터 개선:** 홈 진입 → 계산기 열기 → 첫 입력 → 계산 성공 구간에서 반복적인 이탈이 보이면 진입 동선과 입력 안내를 우선 개선한다. 퀴즈·기록 기능의 투자 순서는 재방문 코호트에서 해당 기능 사용이 확인된 뒤 정한다. 광고는 `session_end`와 `quiz_retry` 위치별 표시·보상·유지율 및 사용자당 수익을 비교할 수 있을 때 판단한다. 노출 빈도를 임의로 높이지 않는다.

## 매주 확인할 지표

- **유입:** 스토어 노출 → 상세 페이지 → 설치 전환율, 신규 사용자 수와 유입 경로.
- **첫 가치:** 첫 실행 사용자 중 계산기 진입, 첫 입력, 첫 성공 결과까지의 단계별 비율과 소요 시간 구간.
- **재방문:** 설치일 기준 D1·D7 재방문 코호트와 퀴즈·기록 이용 여부. 작은 코호트는 실제 분모를 함께 표시.
- **광고:** 연결된 AdMob 데이터로 위치별 요청 대비 채움률, 보상 완료율, ARPDAU, D1·D7 유지율을 함께 비교. 작은 표본의 수익 변동은 결론으로 단정하지 않음.

새 설문, 유료 기능, 광고 빈도 증가는 이 측정 단계의 범위에 포함하지 않는다.
