## 1. 제품 개요

**한 줄 정의**: 술과 관련된 모든 숫자(도수·용량·칼로리·혈중알코올농도)를 계산하고, 음주를 기록·절제하도록 돕는 오프라인 올인원 유틸리티 앱.

**핵심 화면 (= 앱의 존재 이유)**: **실시간 음주 세션**(라이브 BAC 추정)과 **계산기 9종**. 이 둘이 사용자가 앱을 여는 1차 동기이며, 트래커·탐색·퀴즈는 리텐션을 위한 위성 기능이다.

**차별 기능**:
- 술자리 중 잔을 탭할 때마다 30초 주기로 BAC를 재추정하는 **라이브 세션** + 종료 시 운전 가능 추정 시각 **로컬 알림 예약**.
- 세션을 끝내면 남는 **세션 히스토리**(피크 BAC·잔 타임라인·공유 카드 이미지).
- 음주 습관 관리용 **절주 챌린지**와 **주간 음주 목표**(한도 대비 진행·초과 경고).

**타겟** (확정):
- **1순위 — 일반 음주자**: 술자리에서 자기 상태를 확인하려는 사용자(라이브 세션·BAC·안전 확인). **핵심 타겟이며 디자인 우선순위의 기준.**
- **2순위 — 습관 관리자**: 음주량을 줄이거나 관리하려는 사용자(트래커·챌린지·주간 목표).
- **3순위 — 조주 애호가**: 홈브루잉·조주(도수 조정·블렌딩·어는점 계산).
- 공통적으로 **성인 음주자**. 미성년자·비음주자는 타겟이 아니며, 비주얼도 이를 소구해선 안 된다(§2.4).

**플랫폼·뷰포트**: Expo / React Native. **Android 우선**(홈 위젯은 Android 전용), iOS 병행. 기준 뷰포트 360×800, 소형 320px 폭까지 대응. **다크 단일 테마**(라이트는 📦).

**수익모델** (확정): **무료 + 광고(AdMob)**. 구독·인앱결제(IAP) 없음 → **페이월·구매 화면 불필요**. 광고 슬롯은 §2.6. "광고 제거 IAP"는 📦 장기 보류(현재 코드에 없음).

## 2. 공통 규칙 (전 화면 필수 준수)

### 2.1 핵심 데이터 표기 규칙

| 데이터 | 표기 | 예시 |
|---|---|---|
| 용량 | 정수 또는 소수 2자리 + `ml` | `360ml`, `98.68 ml` |
| 도수(ABV) | 입력·표시는 소수 1자리, 계산 결과는 소수 2자리 + `%` | `16.5%`, `8.45 %` |
| BAC | **소수 3~4자리 + `%`** — 반올림으로 자릿수를 줄이지 말 것(0.03과 0.05의 차이가 법적 의미를 가짐). 세션 히어로·히스토리는 3자리, 독립 BAC 계산기·회복 화면은 4자리 | `0.044%`, `0.0582%` |
| BAC 레벨(세션) | 4단계 고정: 안전(<0.02) / 주의(0.02–0.05) / 위험(0.05–0.08) / 매우 위험(≥0.08). 문구 원문은 §2.3 | |
| 칼로리 | 정수 + `kcal` | `139 kcal` |
| 표준잔 | 소수 1자리, 단위어 "표준잔" 병기 (1표준잔 = 순알코올 14g) | `1.4 표준잔` |
| 시각 | `HH:mm`(기기 로케일). 세션·히스토리는 시작–종료 범위 | `23:40`, `22:15 – 23:40` |
| 날짜 | 목록은 로케일 축약형, 계산 기록은 상대 표기("방금 전 / n분 전 / n시간 전 / n일 전", 7일 초과 시 날짜) | `Aug 5`, `3시간 전` |
| 금액 | 천 단위 콤마, 통화 기호 없이 언어별 단위어 | `아낀 술값 약 36,000원` |
| 온도 | 소수 1자리 + `°C` | `-16.0 °C` |
| Proof | 소수 1자리, US/UK 병기 | `US 86.0 / UK 75.3` |
| 챌린지 진행 | `D+연속일수`, 목표는 별도 | `D+12` / `목표 30일` |
| 주간 목표 | `현재잔수 / 한도잔수` + 진행바(초과 시 빨강) | `5 / 7` |
| 도수 범위(백과) | `min–max%` (en dash) | `16–25%` |

### 2.2 핵심 지표의 시각 위계

화면당 "주인공 숫자"는 하나이며 가장 크고 강하게 노출한다. 나머지는 보조.

| 화면 | 주인공 숫자 | 컬러 규칙 |
|---|---|---|
| 라이브 세션 | 현재 BAC(초대형) | BAC 레벨 4색 |
| 세션 히스토리 상세·공유 | 피크 BAC | 초록(강조) |
| 트래커 챌린지 | 연속 절주 일수 `D+n` | 초록 |
| 트래커 주간 목표 | `현재/한도` 잔수 | 한도 내 초록 / 초과 빨강 |
| 퀴즈 결과 | `점수/총점` | 70%↑ 초록 / 40%↑ 노랑 / 그외 빨강 |
| 계산기 | 첫 번째 결과값 | 강조색 |

### 2.3 법적·정책 면책 문구 (원문 그대로, 삭제·축약 금지)

> 아래 문구는 이 앱 도메인(추정치·운전·음주)에서 도출한 **확정 문구**다(디자인·문안에 그대로 사용). 출시 전 법무 검토 1회 예정.

1. **세션 화면 하단(시작 전·진행 중 모두 상시 노출)** — 코드 확정 문구:
   > "이 수치는 Widmark 공식 기반의 참고용 추정치이며 실제 혈중알코올농도와 다를 수 있습니다. 음주 후에는 수치와 관계없이 운전하지 마세요."
2. **세션 danger/high 진입 시 경고 배너** — 코드 확정 문구:
   > 제목 "위험 수준입니다" / 본문 "혈중알코올농도가 위험 범위에 들어섰어요. 물을 마시고 속도를 늦추세요. 절대 운전하지 마세요."
3. **숙취 예측 & 회복 화면 하단**: "의학적 조언이 아니며 개인차가 있습니다." 취지의 면책.
4. **운전 가능 알림**(운전 가능 추정 시각에 발송) — 코드 확정 문구:
   > 제목 "이제 운전할 수 있어요 (추정)" / 본문 "이제 알코올이 대사되었을 시간이에요. 그래도 운전 전 컨디션을 꼭 확인하세요." — 제목에 반드시 "(추정)"을 병기한다.
5. BAC 관련 라벨에는 항상 "(추정)" 병기: "현재 혈중알코올농도 (추정)".
6. 세션·히스토리 공유 카드 하단 고정 푸터: "Widmark 공식 기반 추정치 · 음주 후 운전 금지".

### 2.4 금지사항 (스토어 정책·제품 원칙)

- **BAC 수치를 근거로 "운전 가능"을 긍정하는 어떤 UI도 금지**. 안전(초록) 레벨이라도 "운전해도 됨" 류 문구·아이콘 불가. 세션 레벨명은 §2.3의 고정 문구만 사용한다.
- 음주를 **조장·미화하는 카피 금지**("한 잔 더!", 목표 달성형 음주 게이미피케이션 등). 게이미피케이션은 절주 챌린지·주간 목표·퀴즈에만 적용한다.
- **미성년자 소구 비주얼 금지**(캐릭터·만화풍 술 일러스트, 귀여운 취함 표현 등 지양).

### 2.5 상태 디자인 (로딩·빈·에러 — 공통 컴포넌트로 신규 디자인 필요)

| 상태 | 현재 구현 | 디자인 요청 |
|---|---|---|
| 로딩 | 스플래시 이후 없음(로컬 데이터라 순간 로딩) | 카드형 목록 **스켈레톤 1종**(트래커·탐색·세션 히스토리 공용) |
| 빈 상태 | 이모지 + 1줄 텍스트를 화면마다 임의로 구성(예: 세션 "아직 추가한 잔이 없습니다…", 세션 히스토리 🍺 "아직 저장된 세션이 없습니다…", 트래커 🍷 "오늘 기록이 없습니다") | 이모지·타이틀·설명·(CTA) 요소의 **빈 상태 템플릿 1종**으로 통일 |
| 입력 오류 | OS 기본 Alert 팝업(문구 예: "모든 값은 0보다 커야 합니다") | 앱 톤의 **다이얼로그/토스트 스타일**(문구는 유지) |
| 파괴적 액션 확인 | OS 기본 Alert(세션 폐기, 계산 기록 전체 삭제, 세션·커스텀 술 삭제, 데이터 복원) | 확인 다이얼로그 1종(파괴 버튼 = 빨강 `#EF4444`) |
| 광고 미로드 | 빈 공간 | 배너 자리 placeholder 처리 방안 |

### 2.6 광고 슬롯 (위치는 코드 고정, 디자인 대상 아님 — 레이아웃에 반영만)

AdMob. 개발 빌드는 테스트 광고, 배포 빌드만 실광고. 전면 광고 빈도는 루트 타이머가 아니라 각 호출부에서 `adFrequency` 유틸이 판단한다(전역 최소 간격 3분, sessionEnd는 추가로 12시간 캡).

| 슬롯 | 위치 | 크기 |
|---|---|---|
| 앵커드 배너 | **전 화면 최하단**(탭바 아래) 상시 고정, `insets.bottom` 패딩 | 적응형 배너(높이 ~50–60px) |
| 인라인 배너 | 백과·레시피 목록 **8번째 항목마다**, 문화(두 섹션 사이), 트래커 주간 통계 아래, 레시피 상세 하단, 회복 화면 중간, 세션 히스토리 목록 하단 | 배너(~50px) |
| 전면 광고 | ① 퀴즈 마지막 답변 → 결과 진입 사이 1회 ② **세션 종료·저장 후 1회(단 danger/high 레벨이면 스킵, 12h 캡)** | 전체 화면(OS 제공) |
| 보상형 광고 | 퀴즈 결과의 "광고 보고 다시 도전" | 전체 화면(OS 제공) |

> 모든 스크롤 화면은 하단 패딩 ~100px을 확보해 앵커드 배너·탭바에 콘텐츠가 가리지 않게 한다.

## 3. 화면별 상세

각 화면은 다음 7개 항목 표로 기술한다. 항목명은 좌열 고정, 내용은 우열. 상태 표기가 없으면 ✅구현.

### 3.1 홈 (탭 1) ✅ — 리디자인

| 항목 | 내용 |
|---|---|
| **목적** | "지금 필요한 계산기/기능이 어디 있지?" — 3초 안에 계산기 진입 또는 세션 시작. |
| **구성(위→아래)** | ① 타이틀 "주류 계산기" + 서브 "계산하시려는 항목을 터치해주세요!" ② **라이브 세션 CTA**(대형 카드, 🍻) — 기본: 외곽선 + "지금 마시는 중" / "잔을 기록하며 실시간 BAC 추정치 확인"; **세션 진행 중: 초록 배경 + "세션 진행 중 — 이어서 기록하기"** ③ 섹션 "계산기": **3열 그리드 9개**(원형 컬러 아이콘 + 라벨 1줄). 순서: 도수 조정🧪 / 블렌딩🍹 / 칼로리🔥 / 도수 확인(온도 보정)🌡️ / 알코올량🥃 / 어는점🧊 / Proof 변환🔄 / 혈중알코올농도🍺 / 단위 변환📐 ④ 섹션 "오늘": 오늘의 술 상식 팁 카드(이모지 + 본문 1~3줄) + 오늘의 추천 카드(라벨 뱃지 + 이모지 + 제목 + 설명 + "…보기 ›") ⑤ 퀴즈 배너(🧠 "술 상식 퀴즈 도전하기", 강조 배경) ⑥ 섹션 "즐겨찾기 & 최근 본 콘텐츠": 가로 카드 레일(최대 8, 즐겨찾기 우선·중복 제거). 카드 = 이모지 + Recipe/Guide 뱃지 + 제목 1줄 + 설명 2줄. **콘텐츠 없으면 섹션 전체 숨김** |
| **동작** | 계산기 탭 → 바텀시트(3.2). 세션 CTA → `/session` push. 추천 카드·배너·레일 → 각 대상 화면. 포커스 시 활성 세션 여부·즐겨찾기·최근 콘텐츠를 재조회해 CTA와 레일을 갱신. |
| **데이터 규칙** | 팁·추천 카드는 날짜 인덱스로 순환(팁 90종, 추천 카드 4종). 라벨·본문·액션은 5개 언어 대응. 계산기 라벨은 1줄 말줄임. |
| **인터랙션** | 탭바 탭 시 햅틱. 세션 진행 중 상태는 현재 배경색 변경만 존재. |
| **예정 추가** | 🔜 온보딩 완료 후 첫 진입 시 개인화 인사(체중·언어) 검토. |
| **유의** | CTA가 5종(세션·그리드·오늘·퀴즈배너·레일)으로 경쟁 → **시각 위계 정리가 이 리디자인의 핵심**. 권장 우선순위: 계산기 그리드 ≥ 세션 CTA > 오늘 블록 > 퀴즈 배너 > 레일. 세션 진행 중임이 즉시 보이도록(펄스·타이머 등) 제안 환영. |

### 3.3 라이브 음주 세션 (`/session`, 탭바 밖 전체화면) ✅ — 리디자인 (최우선)

| 항목 | 내용 |
|---|---|
| **목적** | (진행 중) "나 지금 얼마나 취했고 언제 깨?" — 어두운 술집에서 흘긋 봐도 읽혀야 함. |
| **구성 — 상태 A(시작 전)** | ① 헤더(← + "실시간 음주 세션") ② 히어로(🍻 + "지금 마시는 중이라면 세션을 시작하세요" + 설명 2줄) ③ 체중 입력(kg, placeholder 65, 직전 값 자동 채움) ④ 성별 2버튼(남성/여성) ⑤ **[세션 시작]** ⑥ 면책 문구(§2.3-1) |
| **구성 — 상태 B(진행 중)** | ① 헤더(← + 제목 + "진행 중" 뱃지) ② **danger/high면 상단 경고 배너**(⚠️ + §2.3-2, 배경 high=`#7F1D1D`·danger=`#7C2D12`) ③ **BAC 히어로 카드**: "현재 혈중알코올농도 (추정)" + **초대형 수치 `0.044%`(레벨 컬러)** + 레벨 문구(4종 고정) + 레벨 컬러 진행바(0~0.12% 스케일) + 3분할 스탯(표준잔 `1.4` / `139` kcal / 해독 예상 시각 `HH:mm`, 0이면 `—`) ④ 섹션 "잔 추가": **빠른 잔 7종 칩** + **커스텀 술 칩(초록 테두리)** + **[+ 추가] 점선 칩**(커스텀 술 관리 모달 3.14 오픈) ⑤ 섹션 "마신 기록 ({n}잔)" + 우측 "↩︎ 실행 취소"(마지막 1잔 삭제) — 목록(최신 위): 이모지 + "소주 · 50ml · 16.5%" + `HH:mm`; 빈 상태 "아직 추가한 잔이 없습니다. 위에서 마신 잔을 탭하세요." ⑥ **[세션 종료 & 트래커에 저장]** ⑦ [기록 없이 종료] → 확인 다이얼로그("세션을 삭제할까요? / 이 세션의 기록은 저장되지 않습니다.") ⑧ 면책 문구(§2.3-1) |
| **동작** | BAC는 **30초마다** 자동 갱신(수치·레벨·바·해독시각 동시 변화). 종료·저장 시: 잔별 실제 시각으로 트래커 이관 + **세션 히스토리 저장 + (운전가능 시각이 미래이고 알림 ON이면) 운전 가능 알림 예약** + 위젯 갱신 → 트래커로 전환. |
| **데이터 규칙** | Widmark: 표준잔 14g, 분포계수 남 0.68·여 0.55, 대사율 0.015%/h, 에탄올밀도 0.789. 레벨 임계 **0.02 / 0.05 / 0.08**. 빠른 잔 7종 실값은 별첨 B-3. |
| **인터랙션** | 잔 추가 = 중간 햅틱, 실행 취소 = 약한 햅틱, 시작·종료 = 성공 햅틱, **danger/high 최초 진입 = 경고 햅틱**(안전 복귀 시 재무장). |
| **예정 추가** | 🔜 온보딩 도입 시 상태 A의 체중·성별이 프로필에서 자동 채워져 사실상 스킵. 📦 세션 중 잠금화면 알림(Live Activity류). |
| **유의** | **한 손 조작 + 저조도** 전제: 잔 칩·종료 버튼은 엄지 도달 범위, 대비 극대화. 레벨 컬러 전환(초록→호박→주황→빨강)이 은근하면 위험 전달 실패 → 전환 모션 제안 환영. [기록 없이 종료]와 [종료 & 저장]의 시각 차이를 크게. |

### 3.4 탐색 (탭 2) ✅ — 리디자인

| 항목 | 내용 |
|---|---|
| **목적** | "궁금한 술/레시피/음주 문화를 찾을 수 있나?" |
| **구성 — 공통 프레임** | 타이틀 "탐색" + **세그먼트 컨트롤 3개**(백과사전 / 레시피 / 문화, 활성 초록). 딥링크: `?section=`이 세 값 중 하나면 해당 섹션, `?guide=`면 백과로 진입해 해당 카드 자동 펼침. |
| **구성 — 백과사전** | ① 검색 입력("검색") ② **아코디언 카드 목록(25종)**: 접힘 = 이모지 + 이름 + 도수 범위 뱃지 `16–25%`; 펼침 = 칼로리(100ml당)·원산지·적정 온도·어울리는 음식 표 + 설명 ③ 빈 검색: 🔍 + 안내. **8번째마다 인라인 배너.** |
| **구성 — 레시피** | ① 검색 입력 ② 필터 칩(전체/한국/글로벌) ③ **맞춤 레시피 추천 패널**(카드): 스타일 칩(전체/한국/글로벌) + 최대 도수 칩(8/12/18%, 기본 12·재탭 해제) + 최대 칼로리 칩(120/180/260, 기본 180) + 재료 칩(가로 스크롤, 최대 10, 다중 선택) → 매칭 결과 가로 카드 레일(최대 8: 이모지 + 이름 + `8.5% - 142 kcal` + "자세히 보기 ›"); 0개면 빈 카드 ④ 레시피 카드 목록(35종). **8번째마다 인라인 배너.** |
| **구성 — 레시피 상세(바텀시트)** | 드래그 핸들 → 우측 즐겨찾기 토글(★/☆) → 대형 이모지(60px) + 이름 → 난이도 뱃지(easy 초록·medium 호박·hard 빨강) + 카테고리 뱃지 → 재료(이름 + `45 ml` + 도수>0이면 `(40%)`) → 만드는 법 → (있으면) 유래&배경 / 만들기 팁(불릿) / 🍃 가니시 → 요약 카드(총 용량 ml / 예상 도수 % / 예상 칼로리 kcal) → (있으면) [표준잔 가이드 보기] → 인라인 배너 → [닫기]. 마운트 시 즐겨찾기 로드 + 최근 본 콘텐츠 기록. |
| **구성 — 문화** | ① "나라별 음주 문화"(8개국 카드: 국기 이모지 + 국가명 + 관습 불릿 + 에티켓 불릿) ② 두 섹션 사이 인라인 배너 ③ "술·안주 페어링"(10종 카드: 이모지 + 술 + 페어링 불릿 + 💡 팁 박스) |
| **동작** | 백과·레시피 검색은 번역명 부분일치. 레시피 상세는 아래서 위로 슬라이드, 스와이프다운 닫힘. 가이드 이동은 300ms 지연 후 딥링크 push. |
| **데이터 규칙** | 백과 25종, 레시피 35종(한국 10/글로벌 25), 문화 8개국, 페어링 10종. 실값은 별첨 B-5. data/ 콘텐츠는 ja/zh에서 en으로 폴백. |
| **인터랙션** | 아코디언 펼침·접힘, 즐겨찾기 토글. |
| **예정 추가** | — |
| **유의** | 정보 밀도가 가장 높은 탭. 아코디언 펼침 표의 가독성, 추천 패널이 목록보다 시각적으로 무거운 현재 균형의 재검토 필요. |

### 3.5 트래커 (탭 3) ✅ — 리디자인 (최우선)

| 항목 | 내용 |

## 4. 디자인 시스템 요청

### 4.1 컬러
- **다크 단일 테마**로 디자인하되 **시맨틱 토큰**으로 정의(추후 라이트 파생 가능하게). 현재 값은 별첨 C 참고이며 **전면 재량**.
- 필수 토큰: 배경 2단계 / 카드 / 구분선 / 텍스트 3단계 / 브랜드(현재 초록) / **BAC 레벨 4색** / 경고·파괴(빨강) / 차트 2색(잔 수·칼로리).
- OS 상태바·내비게이션바는 라이트 콘텐츠(밝은 아이콘) 고정.

### 4.2 로고·심볼
- **로고·브랜드 컬러 없음 → 신규 제안 필요.** 현재 아이덴티티는 "초록 + 다크 그레이 + 이모지"가 전부.
- 앱 아이콘 리디자인 포함(스토어 노출용). 브랜드 톤은 **"절제·신뢰·정확"**(확정)을 지향하고, 취함·유흥을 과장하지 않는다.

### 4.3 타이포
- 타이포 스케일 + **초대형 수치용 디스플레이 스타일**(BAC·`D+n`·주간 목표·퀴즈 점수·피크 BAC). 5개 언어(ko/en/es/ja/zh) 폭 차이를 견디도록 **길이 1.5~2배 여유**.

### 4.4 아이콘·일러스트
- **아이콘 전략 (확정): 이모지 → 커스텀 아이콘 세트로 교체.** 필요 수량: 계산기 9종 + 프리셋 16종 + 빠른 잔 7종 + 탭 5종 + 콘텐츠 카드용. 통일된 스타일의 세트로 납품한다.
- 미성년자 소구·음주 미화 일러스트 금지(§2.4).

### 4.5 컴포넌트 목록 (코드에 실재하는 것 반영, 토큰+시트로 납품)
1. 컬러 토큰 / 2. 타이포 스케일(디스플레이 포함) / 3. 카드(기본·탭 가능·히어로) / 4. 버튼(주·보조·외곽선·텍스트·비활성·파괴) / 5. 칩(필터 단일선택·다중선택·프리셋·빠른 잔) / 6. 세그먼트 컨트롤(탐색 3분할·모달 2분할) / 7. 입력 필드(숫자+단위·텍스트·대형 멀티라인) + 키보드 대응 / 8. 라디오 2분할(성별) / 9. 토글 스위치 / 10. 바텀시트 프레임(핸들+헤더+스크롤) / 11. 진행바(퀴즈·챌린지·주간 목표·BAC 레벨 스케일) / 12. 스탯 블록(2~4분할) / 13. 목록 아이템(기록·히스토리·타임라인) / 14. 날짜 스트립 셀 / 15. 아코디언 카드(백과) / 16. 뱃지(도수 범위·난이도·진행 중·종류) / 17. 차트 스타일(막대·라인: 축·그리드·색) / 18. 빈 상태·스켈레톤·다이얼로그·토스트(§2.5) / 19. 배너 광고 placeholder / 20. 탭바(5탭+활성) / 21. **BAC 히어로 카드** / 22. **주간 목표 카드** / 23. **세션 공유 카드(캡처용)** / 24. **위젯 카드(2모드)**.

### 4.6 다크모드
- 다크 단일(라이트는 📦). 시맨틱 토큰으로 정의해 파생 가능하게.

### 4.7 접근성
- 텍스트 대비 WCAG AA(4.5:1, 대형 3:1). **특히 BAC 레벨 4색이 다크 배경에서 AA 충족**해야 함.
- 터치 타깃 최소 44×44pt(현재 일부 칩·아이콘 버튼 미달).
- **색상만으로 상태 구분 금지**: BAC 레벨 = 색 + 문구 + 바 위치, 퀴즈 정오답 = 색 + 아이콘, 주간 목표 초과 = 색 + 문구(§2.2). 색맹 대응 병행.
- 코드에 접근성 라벨이 전면 적용돼 있으므로 커스텀 컴포넌트도 스크린리더 흐름을 깨지 않게.
- 시스템 글꼴 확대(최대 200%) 시 초대형 수치 카드가 파손되지 않도록.
